# Features

TchueKAM is a native desktop AI assistant — fast, private, and yours. Here's what it
does, organized by what you'd want to do with it.

## Conversation & voice
- **Natural chat** — ask anything, get answers grounded in your workspace and context
- **Streaming responses** — watch TchueKAM think and answer in real time
- **Voice conversation mode** — talk to TchueKAM hands-free (speech → answer → speech)
- **Push-to-talk voice input** — dictate prompts without touching the keyboard
- **Multi-model** — switch between models per session; bring your own provider/key
- **Searchable history** — every conversation kept, organized by project and easy to find

## Business Hub — AI document platform
The flagship workspace for turning ideas and scans into finished documents.
- **AI Builders** — interactive builders for CVs/résumés, invoices, contracts, pitch
  decks, business plans and more, each with live preview as you answer
- **Batch OCR** — drop in images or PDFs and extract clean, structured text at scale
- **AI Consultant** — ask for guidance and improvements on any document you're building
- **Block workspace** — assemble and edit documents from reusable content blocks
- **ATS scoring** — check a résumé against applicant-tracking systems before you send it
- **Multi-format export** — export finished documents to 8 formats (PDF, DOCX, Markdown,
  and more)

## Image Studio
- **Image generation** — create images from prompts, right inside the app
- **Image understanding** — describe screenshots, diagrams and photos
- **Text from images** — pull text out of any image for reuse

## Agents, skills & automation
- **Agents** — delegate multi-step tasks to focused agents that work on their own
- **Skills library** — a bundled, extensible library of reusable capabilities
- **Scheduled tasks (cron)** — run prompts and jobs automatically on a schedule
- **Background processing** — long tasks (OCR, generation, indexing) run off the UI thread
  so the app never freezes

## Messaging & integrations
- **WhatsApp bridge** — connect a WhatsApp number and chat with TchueKAM from your phone
- **Multi-platform messaging** — unified inbox for connected channels
- **Cloud remote control** — reach your desktop agent from the web at agent.tchuekam.com

## Files, workspace & code
- **Workspace awareness** — TchueKAM understands the folder you're working in
- **File reading & editing** — open, summarize and edit any file
- **Terminal integration** — run commands and read output safely
- **Project memory** — remembers context across sessions, per workspace
- **Multi-language code** — Python, JavaScript, TypeScript, Go, Rust and more
- **Git-aware** — knows your branch, recent changes and history

## Web & vision
- **Web search** — pull in current information when a task needs it
- **URL fetching** — read and summarize web pages
- **Vision** — reason over screenshots and images alongside your text

## Performance
Rebuilt for flagship-desktop responsiveness.
- **Near-instant startup** — the app window paints fast; heavy work loads on demand
- **Instant navigation** — features load the moment you open them, not before
- **Smooth streaming** — responses render at 60 FPS without stutter
- **Low idle footprint** — sits quietly at ~0% CPU when you're not using it

## System integration
- **Native menus & window** — a real desktop app, not a browser tab
- **System notifications** — get pinged when long tasks finish
- **Clipboard integration** — paste text, images or files directly
- **Customizable keyboard shortcuts** — bind everything the way you like

## Privacy & control
- **Local-first** — your conversations stay on your machine unless you choose otherwise
- **Configurable data sharing** — opt in or out per feature
- **Export anything** — download conversations as Markdown or JSON
- **Delete anything** — full data removal in one click

## Cross-platform & always current
- **Windows, macOS & Linux** — one native app across your devices
- **Free & open source**
- **Automatic updates** — new versions install themselves; you're always on the latest
