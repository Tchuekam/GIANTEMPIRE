# 📱 Mobile Companion & PWA Guide

The **TchueKAM Mobile Companion** brings full 24/7 control over your cloud AI agents (`agent.tchuekam.com`) to your iOS or Android device. Pick whichever suits your phone:

- **Android** — [download the app (APK)](#android-app) and install it like any other app.
- **iPhone, iPad, or any browser** — open the Web App and [add it to your home screen](#pwa-install). No App Store needed.

---

## 🤖 Android app (APK) {#android-app}

<AndroidDownload />

### Install the APK

1. Download the APK on your phone with the button above.
2. Open the downloaded file. Android asks whether to allow installs from this source (your browser or file manager) — allow it once.
3. Tap **Install**, then open **TchueKAM Mobile**.

Prefer not to sideload an APK? The [web app](#pwa-install) below works on any phone with nothing to install.

---

## ⚡ Quick PWA Installation {#pwa-install}

<WebAppNotice />

TchueKAM Agent is a Progressive Web App (PWA) — no App Store downloads or manual installs required.

### **iOS (iPhone & iPad)**
1. Open **Safari** and navigate to **[agent.tchuekam.com](https://agent.tchuekam.com)**.
2. Tap the **Share** button (bottom toolbar).
3. Scroll down and select **Add to Home Screen**.
4. Launch **TchueKAM** from your home screen for full-screen, standalone execution.

### **Android (Chrome)**
1. Open **Chrome** and navigate to **[agent.tchuekam.com](https://agent.tchuekam.com)**.
2. Tap the **three-dots menu** (top right).
3. Tap **Install app** or **Add to Home Screen**.

## ⌨️ Mobile Quick-Action Touch Bar

When accessing TchueKAM on a phone or tablet, a **Mobile Quick-Action Touch Bar** automatically docks above your soft keyboard:

| Button | Action | Description |
|---|---|---|
| `[/goal]` | `/goal ` | Start a long-running, autonomous task |
| `[/schedule]` | `/schedule ` | Set up recurring cron automations |
| `[/status]` | `/status` | View active cloud subagents & system usage |
| `[/clear]` | `/clear` | Clear terminal scrollback buffer |
| `[Ctrl+C]` | `SIGINT` | Interrupt/cancel running process |
| `[Tab]` | `Autocomplete` | Trigger file or slash command completion |

---

## 🎙️ Hands-Free Voice Mode

1. Tap the **Voice Mode** button on the bottom toolbar.
2. Converse with your cloud agent using hands-free WebRTC audio streaming.
3. Spoken responses and text transcripts sync automatically with your terminal session.

Stay informed when managing agents on the go:
