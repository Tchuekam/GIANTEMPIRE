# 📱 Mobile Companion & Guide d'Utilisation

Le **TchueKAM Mobile Companion** apporte le contrôle direct de vos agents IA locaux et cloud sur vos appareils mobiles Android et iOS :

- **Android** — [téléchargez l'application (APK)](#android-app) et installez-la directement.
- **iPhone, iPad ou tout navigateur** — l'accès Web App est en cours de déploiement sécurisé.

---

## 🤖 Application Android (APK) {#android-app}

<AndroidDownload />

### Installer l'APK

1. Téléchargez le fichier APK sur votre téléphone via le bouton ci-dessus.
2. Ouvrez le fichier téléchargé. Android vous demande d'autoriser l'installation depuis cette source — autorisez une fois.
3. Appuyez sur **Installer**, puis ouvrez **TchueKAM Mobile**.

## ⌨️ Mobile Quick-Action Touch Bar

When accessing TchueKAM on a phone or tablet, a **Mobile Quick-Action Touch Bar** automatically docks above your soft keyboard:

| Button | Action | Description |
|---|---|---|
| `[/goal]` | `/goal ` | Start a long-running, autonomous task |
| `[/schedule]` | `/schedule ` | Set up recurring cron automations |
| `[/status]` | `/status` | View active cloud subagents & system usage |
| `[/clear]` | `/clear` | Clear terminal scrollback buffer |
| `[Ctrl+C]` | `SIGINT` | Interrupt/cancel running process |
| `[Tab]` | `Autocomplete` | Trigger file or slash command completion |

---

## 🎙️ Hands-Free Voice Mode

1. Tap the **Voice Mode** button on the bottom toolbar.
2. Converse with your cloud agent using hands-free WebRTC audio streaming.
3. Spoken responses and text transcripts sync automatically with your terminal session.

---

## 🔔 Real-Time Mobile Notifications

Stay informed when managing agents on the go:
- Receive Web Push alerts when autonomous `/goal` tasks finish.
- Get notified when commands require security authorization.
- Track scheduled background jobs in real time.
