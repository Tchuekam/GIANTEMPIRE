# Magida — Supermarket Management System

**Magida** is a premier supermarket and retail management enterprise software system created by **Rostand Tchuekam** and developed by **GianTecH Empire**.

Designed to empower supermarkets, retail chains, and wholesale businesses across Cameroon and Africa, **Magida** streamlines complex retail operations, automated inventory tracking, point-of-sale (POS) billing, supplier management, and real-time business intelligence analytics.

### What ships in this release

The shop-floor system: the till, the stock ledger and the reports.

| | |
| --- | --- |
| **Sells without internet** | Sellers sign in, scan or search, apply a discount within their limit, take payment and print a receipt with no connection at all. Sales queue on the device and sync when the network returns. |
| **Never double-counts** | Each sale carries a device-generated identifier, so a retry after a dropped connection is recognised rather than recorded twice. |
| **Five languages** | English, French, Cameroonian Pidgin, Fe'efe'e and Fulfulde, selected per device. |
| **Every payment method** | Cash, MTN Mobile Money, Orange Money, card and other — kept distinct all the way through to the reports. |
| **A stock ledger** | Opening stock, restocks, sales, damage, loss, returns and recounts each write a movement, so any quantity on the shelf can be explained. |
| **Roles and limits** | Admin, manager and seller, with a per-seller discount ceiling enforced at the till. |
| **Pro forma quotes** | Printed quotes on a separate numbering series, so an unaccepted quote never leaves a gap in the receipt sequence. |
| **Reporting** | Daily, weekly and monthly revenue and estimated profit, with breakdowns by product, category, seller and payment method. |

### Requirements

- **Android 5.1** or newer.
- **A Magida shop server** reachable from the phone. One computer on the shop's own wifi is
  enough — no hosting account and no internet connection are required for the shop to trade.

### Installation

1. Download the APK above.
2. Open it. Android asks whether to allow installation from this source — allow it once.
3. Open Magida and enter your shop server's address on the sign-in screen, then press
   **Test connection**. The address is verified before it is saved, and stored per device.
4. Sign in.

When a newer version is published here, the app offers it on the sign-in screen. Updates install
over the existing app and keep all data.

## 🌟 Key Capabilities & Features

### 🛒 High-Speed Point-of-Sale (POS)
- Lightning-fast barcode scanning and checkout interface.
- Support for multiple payment methods (Mobile Money, Orange Money, Cash, Bank Cards).
- Multi-cashier concurrency with individual session reconciliation and fraud prevention.

### 📦 Smart Inventory & Stock Control
- Real-time stock tracking across multiple store locations and warehouses.
- Automated low-stock alerts and smart reorder suggestions based on sales velocity.
- Expiration date tracking and batch/lot management to eliminate inventory waste.

### 📊 Business Intelligence & Financial Analytics
- Instant daily, weekly, and monthly revenue and profit margin reports.
- Comprehensive sales trends breakdown, best-selling product tracking, and cashier performance audits.
- Automated tax compliance and financial export for enterprise reporting.

### 🔄 Multi-Store Synchronization
- Centralized cloud/hybrid synchronization allowing store owners to monitor multiple supermarket branches in real time.
- Offline-first architecture ensuring checkout counters keep operating even during internet or power interruptions.

## 📜 Version History & Changelog

Every release of Magida introduces new capabilities, optimizations, and security updates:

### 🛰️ v1.5.0 (Released August 29, 2026)
- **Fleet Telemetry & Observability**: Integrated real-time device and session telemetry with PostHog, authoritative identity context (install_id, device_id, session_id), and offline event queueing.
- **Crash Recovery & True Session Duration**: Robust 30-second heartbeats prevent metric loss on abrupt OS process kills; orphaned unclosed sessions are automatically recovered on cold startup.
- **Global Error & Performance Monitoring**: Uncaught JS errors, unhandled promise rejections, and React render errors are fingerprinted and deduplicated. Real-world performance monitors track slow API calls (>200ms) and sync cycles.
- **Dynamic Remote Configuration & Feature Flags**: Safe 3-tier runtime configuration (memory -> localStorage -> defaults) with deterministic hash-based percentage rollouts and instant remote kill-switches.
- **3-Tier OTA Update System**: Android web bundle hotfix updater enables JS/CSS fixes without rebuilding APKs, verified with SHA-256 cryptographic hashes.
- **Anonymized Download Tracking**: High-performance download proxy with SHA-256 IP anonymization.

### 🛡️ v1.4.0 (Released August 25, 2026)
- **Route Ordering Isolation**: Explicit routes (`/products/categories/all` and `/customers/campaigns/list`) are declared ahead of generic parameter routes (`/:id`), eliminating 500 Postgres integer type conversion crashes.
- **Offline Outbox Inventory Alignment**: `pushOutboxQueue()` accurately points to `/api/inventory/adjust` with resolved product IDs so offline stock adjustments sync cleanly without stalls.
- **Sales Sync Foreign Key Resilience**: Sales sync validates product IDs against the store catalog. Unmapped or negative offline IDs insert `product_id = null` in `sale_items`, preventing FK violation `23503` rollbacks and ensuring zero transaction drops.
- **Sales History Retention for Deactivated Staff**: Queries use `LEFT JOIN users` so sales made by deactivated or deleted cashiers remain permanently accessible in history, dashboard analytics, and receipt lookups.
- **Store Profile Null-Clearing**: `PUT /api/auth/store` allows clearing optional store profile fields (`phone`, `address`, `email`, `momo_number`, `om_number`, `logo_url`) via conditional updates.
- **Full Backup & Disaster Recovery Coverage**: JSON export and atomic restore include `suppliers`, `customers` (with loyalty points/segments), and `stock_movements` with mapped relational IDs.

### 🔑 v1.3.2 (Released August 22, 2026)
- **Emergency access repaired**: all **8** preset logins (1 Admin, 2 Managers, 5 Sellers) now sign in by **both password and PIN**, online or offline. The Admin entry had silently stopped working on any shop that completed setup — the owner's account took over `admin@store.com` and replaced its credentials.
- **One-tap emergency sign-in**: the *Identifiants de secours* screen now signs you in directly, instead of only listing codes you had nowhere to type. Each account carries a **PIN** and a **Mot de passe** button.
- **Reachable on a fresh install**: the emergency button no longer hides on devices that have never loaded a staff list — the exact devices most likely to need it.
- **Cleaner lock screen**: preset accounts no longer appear as staff cards ahead of your real cashiers.
- **Self-healing**: a preset that was deleted, deactivated or altered is restored on Hub start, without ever overwriting a real account that uses the same address.
